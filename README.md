## 來簡單的介紹一下這個工具
上方的時間為艾奧傑亞時間(ET)與該島當前、接下來的天氣及時間
中間能夠在四個島嶼中自由切換
下方會顯示該島嶼所追蹤的NM，並且能對特定NM進行回報
若有出現新島則可以一鍵刷新所有NM
支持手動輸入出現時間，分為X分鐘前與直接輸入時間
